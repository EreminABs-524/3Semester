Лабораторная работа №1. Интерфейс работы со структурами данных (мини-СУБД).

 Запуск:
   ./dbms --file file.data --query 'КОМАНДА имя [аргументы]'

 Файл: одна строка — одна структура: ТИП имя элемент1 элемент2 ...
   ТИП — первая буква команд этой структуры (M, F, L, S, Q, T).
   Массив, списки, стек и очередь записываются последовательно (от головы/дна к хвосту/вершине).

 Индексы считаются с 0. 
   Результат команды выводится в консоль (строкой или "TRUE"/"FALSE" / "OK" / "ERROR").

 Общие команды
   PRINT имя                        вывести любую структуру на экран
   SAVE                             принудительно сохранить текущее состояние в файл
   LOAD                             принудительно загрузить состояние из файла

 Массив (M)
   MPUSH имя значение [индекс]      добавить в конец (если индекс не указан) или по индексу
   MDEL имя индекс                  удалить по индексу
   MGET имя индекс                  получить по индексу
   MLEN имя                         длина массива
   MREPLACE имя индекс значение     заменить по индексу

 Односвязный список (F). 
   FPUSH имя значение режим [опора] добавить элемент (режим: head, tail, before, after; 
                                    опора — значение, перед/после которого вставить, для before/after)
   FDEL имя режим [опора]           удалить элемент (режим: head, tail, before, after, value; 
                                    для value опора — само значение)
   FGET имя режим [индекс]          прочитать (режим: all, head, tail, index)
   FSEARCH имя значение             поиск по значению (выводит индекс или -1)

 Двусвязный список (L). 
   (Команды полностью аналогичны F, но начинаются с буквы L)
   LPUSH имя значение режим [опора] добавить элемент
   LDEL имя режим [опора]           удалить элемент
   LGET имя режим [индекс]          прочитать (доп. режим: reverse — вывод с конца)
   LSEARCH имя значение             поиск по значению (выводит индекс или -1)

 Стек (S)
   SPUSH имя значение               положить на вершину
   SPOP имя                         снять с вершины (выводит снятый элемент или EMPTY)
   SGET имя                         посмотреть вершину, не снимая (выводит элемент или EMPTY)

 Очередь (Q)
   QPUSH имя значение               добавить в конец
   QPOP имя                         забрать из начала (выводит элемент или EMPTY)
   QGET имя                         посмотреть первый элемент, не забирая (или EMPTY)

 Дерево (T) — Вариант 4, ключи — строки
   TINSERT имя ключ                 добавить элемент в дерево
   TGET имя ключ                    поиск элемента: TRUE / FALSE 
   ISFULL имя                       проверить, является ли дерево полным (Full): TRUE / FALSE
